# Быстрый старт

## Установка зависимостей

```bash
cd frontend
npm install
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

## Переменные окружения

Убедитесь, что файл `.env` содержит:

```
VITE_API_URL=http://localhost:5000/api
VITE_WS_URL=http://localhost:5004
```

## Функциональность

### ✅ Реализовано:

1. **Авторизация и регистрация**
   - Страница входа/регистрации
   - Сохранение токена и данных пользователя
   - Автоматический редирект после входа

2. **Управление компаниями**
   - Создание компаний
   - Просмотр списка компаний
   - Красивый UI в стиле Apple

3. **Лента новостей (Feed)**
   - Создание постов
   - Просмотр всех постов
   - Анимации при загрузке

4. **Чат с WebSocket**
   - Создание чатов
   - Отправка сообщений через WebSocket
   - Получение сообщений в реальном времени
   - Красивый интерфейс чата

## Дизайн

- Стиль Apple (минималистичный, чистый)
- Плавные анимации (Framer Motion)
- Адаптивный дизайн
- Современный UI с Tailwind CSS
